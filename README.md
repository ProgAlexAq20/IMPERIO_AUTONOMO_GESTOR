# 📖 Sobre

O **Império Autônomo Gestor** é uma aplicação desenvolvida para concentrar diversas ferramentas de produtividade em um único ambiente.

A proposta do projeto é reduzir a quantidade de aplicativos utilizados no dia a dia, oferecendo uma experiência integrada para organização pessoal, planejamento e gestão de atividades.

Além de servir como ferramenta de uso próprio, o projeto também representa minha evolução prática no desenvolvimento web moderno, arquitetura de aplicações e integração com Inteligência Artificial.

# 🛠 Como executar

Clone o projeto

```bash
git clone https://github.com/ProgAlexAQ20/IMPERIO_AUTONOMO_GESTOR.git
```

Entre na pasta

```bash
cd IMPERIO_AUTONOMO_GESTOR
```

Abra o arquivo `index.html`

ou utilize uma extensão como **Live Server**.
